### 📌 Sobre o Projeto

**O SISCOTA (Sistema de Distribuição de Cotas de Serviço dos Bombeiros Comunitários)** é um sistema web projetado como Projeto Integrador no curso de Engenharia de Software da UNISATC para atender diretamente o setor B3 do Corpo de Bombeiros Militar de Urussanga (SC). O projeto tem como objetivo principal automatizar a gestão e distribuição das cotas dos serviços operacionais do corpo de Bombeiros Comunitários. A solução surge para substituir a antiga planilha em Excel, eliminando a complexidade do processo manual de distribuição.
